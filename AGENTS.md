# GOV-01 Project Working Rules

I am a beginner AI/ML student building the GOV-01 Road Damage Image Classifier.

## How to work on this project

1. Inspect the current project files before changing anything.
2. Work on one small, approved task at a time. Do not build the entire project in one step.
3. Explain plans, changes, and technical terms in beginner-friendly language.
4. Do not add unnecessary frameworks, deployment tools, APIs, or complex architecture.
5. Follow the current Module 8 stage. Do not train models before the Data Audit is completed and documented.
6. Never invent dataset findings, metrics, screenshots, experiment results, or model performance.
7. Keep raw datasets, ZIP archives, model artifacts, secrets, and API keys out of Git.

## For every meaningful change

1. Plan the smallest useful change.
2. Make only the agreed change.
3. Check that the result works or is correct.
4. Summarize the files changed and remaining risks.
5. Suggest a short, meaningful Git commit message after verification.

I must be able to understand and explain every submitted part of this project during the final defense.
