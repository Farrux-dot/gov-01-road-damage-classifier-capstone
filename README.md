# Dataset

## Source

[Kaggle Pothole Detection Dataset](https://www.kaggle.com/datasets/abhinavkulshreshth/pothole-detection-dataset) by `abhinavkulshreshth` (listed on Kaggle as CC0).

## Download instructions

1. Open the dataset link above and sign in to Kaggle if prompted.
2. Select **Download** to save the dataset ZIP file.
3. Extract the archive into `data/raw/` in this repository.
4. Confirm `data/raw/` contains the `train`, validation (`val`, `valid`, or `validation`), and `test` splits, with `Normal` and `Pothole` image folders in each split.

The downloaded dataset is not committed to this repository.
